# B70 LCD inference view

ThermalWriter on `b70-host` runs `b70-display.service` as a user service. It samples llama.cpp's active-slot counters about every two seconds over the private libvirt network. LIVE rates are token-count changes divided by elapsed time on the VM for matching requests; a rate is blank until two samples show progress. Short phases may finish between samples. When idle, LAST shows the latest completed request's journal timings (up to 24 hours old, from the current `flint-inference.service` invocation). If slot telemetry is temporarily unavailable, the display falls back to LAST. The helper reads the server's existing API key file for loopback `/slots` requests only; no key, full journal records, or prompt/output text crosses SSH.

- Host: `collector.py`, a locally generated SSH identity (`snapshot_ed25519`), and a verified guest `known_hosts` entry under `~/.config/thermalwriter/b70-display/`. Install `b70-inference.svg` under `~/.config/thermalwriter/layouts/svg/`, `b70-midnight.png` under `~/.config/thermalwriter/backgrounds/`, and the unit under `~/.config/systemd/user/`.
- Guest: `snapshot.py` at `~/.local/libexec/b70-display-snapshot.py`. The collector's public key has `from="192.168.122.1",restrict,command="/usr/bin/python3 -I /home/mike/.local/libexec/b70-display-snapshot.py"` in `~/.ssh/authorized_keys`; the helper accepts only `snapshot` and uses the user's existing journal access. Do not reuse an interactive key.

The [llama.cpp HTTP server docs](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md) describe `/health` and the opt-in `/metrics` endpoint; no metrics-enabled restart is needed. [ThermalWriter 0.1.4](https://github.com/mgaruccio/thermalwriter/tree/v0.1.4) supports composing backgrounds in SVG mode and changing layout variables over D-Bus. [OpenSSH](https://man.openbsd.org/sshd.8#AUTHORIZED_KEYS_FILE_FORMAT) documents the key restrictions; [journalctl](https://www.freedesktop.org/software/systemd/man/latest/journalctl.html) documents structured filtering by service and invocation.

On the host, `systemctl --user status b70-display.service`, `journalctl --user -u b70-display.service`, and `~/.cargo/bin/thermalwriter ctl status` check the installed path. Expect `svg/b70-inference.svg`, `connected: true`, and real rates when the current inference process has completed a request. On the guest, `systemctl show flint-inference.service -p MainPID -p InvocationID` checks process continuity. To remove the integration, disable the collector, set ThermalWriter's active and default layouts back to `svg/neon-dash-v2.svg`, and revoke the dedicated guest authorized-key entry before deleting the helper and host identity.
