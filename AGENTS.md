# Repository guidance

For every performance comparison, read and follow [BENCHMARKING_STANDARDS.md](BENCHMARKING_STANDARDS.md). It is the standard benchmarking process for this repository.

Declare the run tier, baseline, intentional configuration differences, and test process before running. Retain exact commands, environment details, failures, and raw results. Complete the publication checklist before calling results standard-compliant; label incomplete or exploratory runs as development results.

Do not change persistent inference launchers or promote an experimental configuration unless explicitly requested. Keep benchmark workloads, dependencies, and runtimes outside the interactive Pi environment.
